# Security Policy

## Supported version

Security fixes are applied to the latest revision on `main`.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting feature instead of a public issue. Include reproduction steps, affected files, impact, and any suggested mitigation. Do not include credentials, access tokens, proprietary fab data, or personally identifiable information.

The application is an analysis prototype. Uploaded files are processed in the running Streamlit process; operators remain responsible for deployment access controls, retention, and data classification.
